# **App Name**: PANDUS MULTIBIZ INTERNATIONAL VENTURES

## Core Features:

- Vendor Account Creation & Onboarding: Allow vendors to register, create profiles, and undergo an approval process managed by the admin.
- Vendor Service Management Dashboard: Provide a 'cpanel'-like interface where vendors can list, edit, price, and manage all their offered services.
- AI-Powered Service Description Assistant: A generative AI tool that helps vendors quickly create compelling and well-structured descriptions for their services based on brief inputs or keywords.
- Vendor Subscription & Payment Gateway: Enable vendors to make payments for platform access and manage their subscriptions for the multi-services platform.
- Personalized Vendor Storefront URLs: Generate unique, shareable public URLs for each approved vendor, showcasing their available services to potential customers.
- Admin Management Portal: A comprehensive admin interface for overseeing the entire system, including vendor approval, service moderation, and platform settings.
- Customer-Facing Service Display: A public view for customers to browse a vendor's services through their unique URL, facilitating discovery and engagement.

## Style Guidelines:

- Color Anchor: Emulating the existing professional and modern aesthetic of https://cooperativesociety.vercel.app/. The chosen scheme is dark.
- Primary color: A vibrant, clear blue (#4472C4) to represent trustworthiness and technology, aligning with existing branding. (HSL: H:217, S:65%, L:52%)
- Background color: A very dark, desaturated blue (#191E24), providing a deep and focused canvas for content. (HSL: H:217, S:20%, L:12%)
- Accent color: A bright aqua (#5FD5ED) for calls-to-action, highlights, and interactive elements, providing clear contrast. (HSL: H:187, S:70%, L:65%)
- All text will use 'Inter', a modern sans-serif typeface, ensuring excellent readability for both headlines and extensive body content across various device sizes. Note: currently only Google Fonts are supported.
- Use clean, contemporary, and outline-style icons to visually represent services, navigation, and administrative actions, maintaining a minimalist aesthetic.
- Implement a responsive, modular layout featuring a fixed left-hand navigation sidebar for consistent access and a dynamic main content area. Utilize card-based components for structured presentation of services and data.
- Incorporate subtle hover effects on interactive elements and smooth transitions for state changes and view navigation, enhancing user experience without being distracting.
